Практическая работа №1 — Развёртывание PostgreSQL и загрузка Olist

Использована СУБД PostgreSQL 17, развёрнутая в Docker-контейнере `mosud-postgres`.

База данных называется `olist`. Исходные таблицы размещены в схеме `olist`, учебная схема `lab` создана отдельно.

Набор данных Olist состоит из 9 CSV-файлов. Импорт выполнен с помощью `psql` и команды `\copy`. Из-за использования Docker CSV-файлы предварительно копировались в контейнер.

Фактическое количество строк: customers — 99 441; orders — 99 441; order_items — 112 650; order_payments — 103 886; order_reviews — 99 224; products — 32 951; sellers — 3 095; geolocation — 1 000 163; product_category_name_translation — 71.

Проверка ключевых полей показала отсутствие `NULL`. Проверка ссылочной целостности также прошла успешно: количество осиротевших записей для order_items, products, sellers, payments и reviews равно 0.

После загрузки данных выполнена команда `ANALYZE` для таблиц схемы `olist`.

Файл `check.sql` содержит контрольные запросы для проверки количества строк, NULL и ссылочной целостности и успешно выполняется одним запуском.
