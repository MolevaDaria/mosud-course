## 3. Дубликаты и эквивалентность (3-5 предложений)

В SQL запрос `SELECT` по умолчанию возвращает мультимножество, то есть может содержать дубликаты строк. Математическая операция проекции π (в классической реляционной модели) удаляет повторяющиеся кортежи, превращая результат в множество. 

В нашем случае проверка показала: `total_rows` = 10890 и `distinct_rows` = 10890 (`has_duplicates = NO`). Это объясняется тем, что в таблице `order_reviews` поле `order_id` уникально для каждого отзыва, поэтому дубликатов строк в выборке не возникает. Тем не менее, для строгого соответствия реляционной алгебре следовало бы использовать `SELECT DISTINCT`. 

Все три варианта SQL-запросов (исходный, разбитый на два шага и с ранним исключением столбцов) вернули одинаковое количество строк (10890), что подтверждает эквивалентность преобразований. Это демонстрирует важное свойство реляционной алгебры: порядок применения выборок и проекций можно менять, если проекция не удаляет атрибуты, используемые в предикате.
