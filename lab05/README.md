# Практическая работа № 5. Кванторы, EXISTS и реляционное деление

**Вариант 6.** Множество S = {PA, AM, RO}.

## 1. Реализации

1. **Двойной NOT EXISTS.** Формализует условие «не существует такого штата из S, для которого не существует доставленного заказа с этой категорией». Позволяет найти все категории, которые встречались во всех трех штатах.
2. **GROUP BY / HAVING COUNT(DISTINCT).** Группирует продажи по категориям и оставляет те, у которых количество уникальных штатов из S равно мощности S (3). Позволяет быстро получить тот же результат.
3. **EXCEPT + NOT EXISTS.** Берет все категории, которые продавались, и вычитает те, которые отсутствуют хотя бы в одном из штатов S.

## 2. Проверка эквивалентности

Обе проверки (NOT EXISTS EXCEPT HAVING и HAVING EXCEPT NOT EXISTS) вернули **0 строк** (diff_rows = 0). Это строгое математическое доказательство того, что все три реализации возвращают одно и то же множество категорий.

## 3. Пустой делитель

При пустом `target_states` (0 строк) двойной `NOT EXISTS` по логике «для всех» (vacuous truth) возвращает **все** товары из таблицы `products`. Запрос вернул **32341** строку (общее число строк в products с непустой категорией). Это подтверждает, что условие «для всех элементов пустого множества» автоматически истинно.

## 4. Диагностика

Для категории `beleza_saude` распределение заказов по штатам:
- PA: 99 заказов
- AM: 15 заказов
- RO: 23 заказа
Это подтверждает, что категория действительно встречалась во всех трёх штатах S.

## 5. Контрольные вопросы

1. **Как переписать «для всех x выполняется P(x)» через «не существует»?**
   `∀x P(x)` ≡ `NOT EXISTS (x, для которого NOT P(x))`.
2. **Почему COUNT(DISTINCT state) должен сравниваться с мощностью делителя?**
   Потому что «для всех штатов из S» означает, что категория должна встретиться в каждом из |S| штатов. Если количество уникальных штатов, где она продавалась, равно |S|, значит, она покрывает их все.
3. **Что происходит с универсальным условием, если множество обязательных элементов пусто?**
   Оно считается истинным по определению (vacuous truth). Это означает, что пустое множество требований автоматически выполняется для любого объекта.ø
